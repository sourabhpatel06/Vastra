Vastra is a full-stack e-commerce clothing web application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The platform provides a responsive and user-friendly interface where users can browse products, search for items, manage their cart and wishlist, and place orders. It includes secure user authentication using JWT, RESTful APIs, and MongoDB for efficient data management. An admin panel is also available to manage products, users, and orders.

Technologies: MongoDB, Express.js, React.js, Node.js, JavaScript, Tailwind CSS, REST APIs, JWT.
